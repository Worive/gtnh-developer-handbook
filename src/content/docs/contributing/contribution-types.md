Different changes have different owners and review needs:

- **Mod code:** work in the owning mod repository and test both its development
  environment and relevant full-pack interactions.
- **Pack configuration or resources:** start in GT-New-Horizons-Modpack and test
  the assembled result.
- **Quest changes:** follow the repository's current quest-development guide.
- **Build tooling or automation:** identify the affected GTNHGradle,
  RetroFuturaGradle, workflow, or assembly repository before editing.
- **New mods or major content:** discuss the proposal before implementation and
  use the current ExampleMod starter when accepted.

Use the [repository map](/gtnh-developer-handbook/concepts/repository-map/) for
the likely owner. The target repository's instructions remain authoritative.
